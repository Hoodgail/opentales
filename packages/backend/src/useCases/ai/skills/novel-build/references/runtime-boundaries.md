# Durable runtime boundaries

- Treat persisted task dependencies, authorization scopes, leases, budgets, and acceptance criteria as hard constraints.
- Use only the assigned build run and manuscript units; never substitute the canonical/default manuscript branch.
- Persist observable artifacts, state, diagnostics, versions, and evidence. Never use self-reported checks as proof.
- Stop at a human checkpoint, exhausted bounded revision, expired authority, budget fence, or verified external blocker.
